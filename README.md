# My Website App for Android (MIT App Inventor)

An **Android app that opens my early website** ([ggdrishtant.wixsite.com/website](https://ggdrishtant.wixsite.com/website), built with Wix) in a web viewer. Built with [MIT App Inventor](https://appinventor.mit.edu/), a block-based tool for making Android apps.

## Download

Install the prebuilt APK: [`MYWEBSITE.apk`](MYWEBSITE.apk)
